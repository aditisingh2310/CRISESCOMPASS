# CrisisConnect - Judges' Quick Start Guide

## 🎯 What You're Looking At (10 seconds)

This is **CrisisConnect**, a real-time disaster response platform that coordinates crisis response through:
- **Live incident reporting** with location-based crowdsourcing
- **Real-time map visualization** with intelligent clustering
- **AI-powered emergency guidance** for safety instructions
- **Automated alert broadcast** for critical incidents
- **Resource coordination** dashboard for responders

---

## 🚀 Try These Features Right Now

### 1. **Enable Demo Mode** (30 seconds)
- Click the **🎮 Demo Mode** button (top-right)
- Watch incidents appear automatically on the map
- See the live stats panel update
- Notice how critical incidents trigger alerts

### 2. **Check the Map Legend** (5 seconds)
- Look at the **Map Legend** panel (top-left)
- Understand that:
  - 🔴 Red = Fire
  - 🔵 Blue = Flood
  - 🟢 Green = Medical
  - 🟠 Amber = Shelter
  - 🔴 Dark Red = SOS

### 3. **View Impact Metrics** (5 seconds)
- See 4 key metrics (top-left panel):
  - Incidents Reported
  - People Assisted
  - Average Response Time
  - System Uptime

### 4. **Test SOS** (10 seconds)
- Click the **🚨 SOS Emergency** button (bottom-left)
- Your location is sent instantly
- Alert appears on map
- Notification confirms delivery

### 5. **Report an Incident** (20 seconds)
- Click **📝 Report Incident** button
- Fill in incident type, description, location
- See it appear on map in real-time

### 6. **View Dashboard** (30 seconds)
- Navigate to **📊 Dashboard** (top navigation)
- See:
  - Crisis Intelligence summary
  - Incident timeline (chronological)
  - Emergency alert panel
  - Live statistics
